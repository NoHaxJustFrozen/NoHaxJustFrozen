### A bit about me

Hey, I'm **Çınar**. I build web applications, backend services, desktop tools, and custom systems for FiveM servers. I enjoy moving between frontend work, server-side logic, and the small details that make a project feel finished.

I mainly work across **JavaScript, TypeScript, React, Lua, SQL, and Java**, alongside **Ruby, Python, and C#**. I'm also interested in hardware integration, especially working with vehicle diagnostics and live data.

I like code that's easy to read, interfaces that aren't a chore to use, and learning something new along the way.
